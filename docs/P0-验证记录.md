## 关键实现边界

- PF 状态请求采用候选 216 字节 ABI。静态断言和编码测试不能证明运行内核的兼容性。
- 为覆盖 floating state，状态接口字段不用于过滤；指定接口用于执行前检查本机 IP 确实属于本机该接口。
- 为覆盖由服务端先发包建立的状态，分别匹配两个方向，且始终保留精确本机服务端口。
- 两次 ioctl 不是原子事务，调用成功也不代表之后的流量被规则阻断。
- 实验性撤权暂时拒绝 IPv6 link-local 地址，防止接口 scope 不明确。完整 IPv6 兼容性尚未验收。
- 原型只生成独立 anchor 内容，没有 root anchor 自动挂载器；未经审查不能作为主规则集加载。
- 生成器包含配置端口的反向规则。最终产品必须验证主动出站程序复用该源端口、NAT、VPN、其他 quick 规则等场景，避免将当前实验范围当成完整入站过滤覆盖。
- 当前没有桌面 UI、常驻服务、安装包或 Windows 执行层。
