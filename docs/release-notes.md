桌面预览包：提供 Port Guard 界面、本地 SQLite 和现有只读诊断能力。后台常驻防火墙服务和 Windows WFP 执行层尚未完成；安装预览包不会自动启用防火墙规则。

- Windows x64：下载 `windows-x64.exe` 安装包。
- Mac Apple 芯片：下载 `macos-arm64.dmg`。
- Mac Intel：下载 `macos-x64.dmg`。
- `SHA256SUMS` 包含三个安装包的 SHA-256 校验值。

当前安装包未配置开发者代码签名和 macOS 公证，系统可能提示未知发布者或无法验证开发者。Windows 目标机缺少 WebView2 时，安装过程需要联网。
